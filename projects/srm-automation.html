Overview

After running the sizing process for the SRAD H-Class motor largely by hand and in scattered MATLAB scripts, I built a single MATLAB GUI to formalize and speed up that workflow — a tool that takes a motor from target operating pressure to a finished closure fastening plan in one continuous pass.

Pressure & Throat Sizing

The user sets chamber size or a target operating pressure, which fixes the motor's operating pressure. From there, the tool calculates the throat diameter needed to sustain that pressure with minimal grain surface area — the first constraint that shapes every downstream decision.

Grain Geometry Optimization

With the throat and pressure fixed, the propellant solver optimizes grain geometry across multiple candidate pattern types analytically, rather than through iterative simulation, to converge on a workable design.

Nozzle Contour

Based on the selected manufacturing technique, the tool calculates either a full contoured nozzle or a simpler conical geometry for optimum expansion — the same manufacturing-driven trade-off I had to work through by hand on the SRAD motor, now generalized.

Closure & Retention

Finally, based on operating pressure and the user's choice of retention method, the tool calculates either the correct bolt size and pattern for a bolted closure, or the correct thread size and engagement length for a threaded closure.

Validation & Related Work

I'm currently validating the tool's outputs against hand calculations and known reference motors. This work pairs with an RK4-based internal ballistics physics modeler I developed and submitted as an abstract to IREC — a complementary numerical approach to grain burn simulation, alongside this tool's fully analytical method.

Status

All four modules are functional end-to-end. Validation against reference data is ongoing.
